# 📱 Web Application (`apps/web`)

The **Career Copilot Web Dashboard** is built with Next.js (App Router), React, Tailwind CSS, Framer Motion, and Lucide icons.

---

## 🚀 Features

1. **AI Resume Matcher**: Interactive resume parsing and ATS gap analysis with real-time match scoring.
2. **Smart Job Board**: Real-time job filtering by workplace type (Remote, Hybrid, On-Site) with AI Match percentage badges.
3. **Cover Letter Studio**: AI-assisted cover letter generator supporting custom tone parameters.
4. **Interactive Interview Simulator**: Roleplay technical and behavioral mock interviews with live AI scoring.

---

## 🛠️ Running Locally

```bash
npm install
npm run dev
```

App runs at `http://localhost:3000`.
